# Subnautica 2

## Launch options

```text
gamescope -W 5120 -H 2160 -r 120 -f --force-grab-cursor --prefer-output DP-3 -- %command%
```

## Compatibility

No per-game override. Steam default.

## Flags

| Flag                    | Meaning                                         |
|-------------------------|-------------------------------------------------|
| `-W 5120 -H 2160`       | gamescope outputs at 5120x2160                  |
| `-r 120`                | Game refresh rate 120                           |
| `-f`                    | Fullscreen                                      |
| `--force-grab-cursor`   | Always relative mouse mode                      |
| `--prefer-output DP-3`  | Show on the external monitor on `DP-3`          |

## Hardware

5120x2160 monitor on connector `DP-3`. Change the connector and resolution to match yours.
