# The Riftbreaker

## Launch options

```text
gamescope -f --force-grab-cursor -- %command%
```

## Compatibility

No per-game override. Steam default.

## Flags

| Flag                  | Meaning                                                              |
|-----------------------|----------------------------------------------------------------------|
| `-f`                  | Fullscreen                                                           |
| `--force-grab-cursor` | Always relative mouse mode; keeps the cursor locked inside the game  |
